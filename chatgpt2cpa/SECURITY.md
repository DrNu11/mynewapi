# 安全策略

`chatgpt2cpa` 会处理 `access_token`、`refresh_token`、`id_token` 等敏感认证数据。为了降低暴露风险，项目默认只面向本机使用。

## 支持范围

原则上只为默认分支上的最新代码和最新发布版本提供安全修复参考。历史版本不保证继续维护。

## 报告方式

- 不要在公开 Issue、PR、讨论区或截图里贴真实 token、session JSON、浏览器导出文件或可复用的凭证
- 如果仓库启用了 GitHub Private Vulnerability Reporting，请优先使用私密报告
- 如果没有启用，请用不包含敏感数据的最小复现方式联系仓库维护者，或先提交不带细节的占位 Issue，等待转到私下渠道

## 建议报告内容

- 问题影响范围
- 复现步骤
- 预期行为与实际行为
- 是否可能导致 token 泄漏、错误导出、越权访问或公网暴露
- 已做过的脱敏说明

## 部署边界

- 不建议把这个工具直接部署到公网
- 默认绑定 `127.0.0.1`
- 如需显式监听 `0.0.0.0`，请自行承担网络暴露风险，并配套做好访问控制
