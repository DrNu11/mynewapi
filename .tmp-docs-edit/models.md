## 怎么选模型

| 场景 | 推荐模型 |
| --- | --- |
| 日常聊天 / 文案 | `gpt-5.4-mini` 或 `gpt-5.2` |
| 复杂任务 / 多模态 | `gpt-5.5` 或 `claude-opus-4-6` |
| AI 编程（Claude Code / CodeX） | `gpt-5.3-codex` 或 `claude-sonnet-4-5` |
| 交互式编码 / 即时补全 | `gpt-5.3-codex-spark` |
| 高性价比推理 | `deepseek-v4-flash`、`MiniMax-M2.7` 或 `glm-5.1` |
| Gemini 生态 | `gemini-3-pro-preview` 或 `gemini-2.5-pro` |
| 图像生成 | `gpt-image-2` 或 `grok-imagine-image-lite` |

## 计价说明

- 表格价格为客户侧人民币价格，单位是 **RMB / 1M tokens**。
- 1K tokens 价格可按表格数值除以 1000 估算。
- 实际扣费会受账号分组、缓存命中、特殊活动或上游策略影响，最终以控制台账单为准。
- `ModelPrice` 当前为空，模型均按站内倍率计费。

## 查询所有模型（API）

如果你想通过 API 实时获取当前账号可调用的模型，执行：

```bash
curl https://api.nassaapi.xyz/models \
  -H "Authorization: Bearer $YOUR_API_KEY"
```

返回示例：

```json
{
  "object": "list",
  "data": [
    { "id": "gpt-5", "object": "model", "owned_by": "nassaapi" },
```
